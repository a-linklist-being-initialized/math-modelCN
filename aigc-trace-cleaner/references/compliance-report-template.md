# 《AI 合规自查报告》模板（国赛 2026 标准版）

> 触发：用户要求"国赛 AI 合规自查""AI 红线检测""按自查表核查论文"时使用。
> 与《AI 痕迹检测报告》（`report-template.md`）并列，**不替代**：前者查官方红线与硬指标，后者查文风 AI 味。两者可同时交付。
> 输入四件套：参赛论文 + 比赛题目 + 附件（如有）+ 自查表；缺项须在报告开头声明"该项判定为待核实"。

## 报告必备五段（顺序不可调）

```markdown
# AI 合规自查报告 ——《论文标题》

- 生成时间：YYYY-MM-DD
- 核查依据：2026 数学建模国赛 AI 全自动自查表（标准版）· 6 维度 26 条
- 输入清单：论文 ✅ ｜ 题目 ✅/❌（缺则题意类判待核实）｜ 附件 ✅/❌ ｜ 自查表 ✅
- **整体合规判定：合规 / 基本合规（有一般缺陷）/ 存在致命扣分项 / 无法判定**
- 结论摘要：合格 X 条 ｜ 存在问题 Y 条 ｜ 待核实 Z 条（共 26 条）

## 一、自查结果汇总表
| 一级维度 | 条数 | 合格 | 存在问题 | 待核实 | 风险等级 |
|---|---|---|---|---|---|
| 一、2026 国赛 AI 新规合规 | 4 | … | … | … | 🔴/🟡/🟢 |
| 二、AI 幻觉与数据真实性 | 4 | | | | |
| 三、建模逻辑与题意适配 | 5 | | | | |
| 四、模型求解及结果合理性 | 3 | | | | |
| 五、官方写作规范 | 6 | | | | |
| 六、官方排版与页数 | 4 | | | | |
| **合计** | **26** | | | | |

## 二、逐条核查明细（26 条，按维度顺序）
### 一、2026 国赛 AI 新规合规
#### 核查 1：核心建模 AI 主导痕迹检测
- **结论**：存在问题（🔴 致命扣分）／合格／待核实
- **问题位置**：第 X 章第 Y 段（页码或小节号）
- **证据（原文摘录）**："……"（引用不超过 60 字）
- **判定理由**：为什么这构成/不构成违规（引用自查表对应判定要点）
- **整改建议**：具体到"补什么、放在哪、怎么改"，不接受"建议优化"
- （每条同此结构，共 26 条；无问题的条目也要写"合格 + 依据"，不得省略）

## 三、问题分级汇总
- **致命扣分项（🔴）**：列出编号 + 一句话 + 影响（如"踩 AI 红线，可能取消评奖资格"）
- **一般缺陷（🟡）**：列出编号 + 一句话
- **轻微瑕疵（🟢）**：列出编号 + 一句话

## 四、优先级整改清单（按扣分权重排序）
| 优先级 | 编号 | 问题 | 整改动作 | 预计耗时 | 验证方式 |
|---|---|---|---|---|---|
| P0（先改） | … | … | … | … | 改完复跑 scan.mjs 对应指标 |
| P1 | … | | | | |
| P2 | … | | | | |
> 排序原则：官方硬红线（AI 主导/声明不实/幻觉/匿名）> 结构性缺失（漏题、缺检验、缺模块）> 规范硬指标（摘要字数、页数、假设条数）> 文风类。

## 五、官方规范适配度与潜在风险预警
- **规范适配度**：摘要（字数/单页）、正文页数、假设条数、三大检验、匿名、三线表与公式编号——逐项给"当前值 → 官方要求 → 差距"
- **潜在风险预警**：可能被评委直接扣分或质疑的点（按严重度排序），以及"文本层查不到、需人工核验"的清单（配色是否默认模板、图片清晰度、页数实际值、匿名信息是否在页眉页脚）
- **下一步建议**：3 条以内，可直接执行
```

## 输出与交付要求（源自自查表）

1. **默认 Markdown 报告**（便于二次编辑）；
2. 用户要求"精美版"时：按 `report-template.md` §2 的 HTML 样式出**可视化 HTML**（汇总表用色块、问题卡片分级配色、进度条/雷达图展示各维度通过率），并说明可另存/打印为 PDF；
3. 用户要求 Word/PDF 时：**用本仓库技能链生成**——`.docx` 走 `docx-cn` 技能，PDF 由 Word 另存或 soffice 转换（不臆造转换结果，转换失败要如实报告）；
4. 报告中的**每条结论必须带位置或证据**；无证据的条目一律"待核实 + 写明需人工核验什么"；
5. **不得**为了好看把"待核实"写成"合格"；**不得**承诺"改完一定能过 AI 检测"。

## 与痕迹检测报告的分工（同时交付时的编排）

```markdown
# 论文 AI 全面体检报告（合并版）
## 第一部分：国赛 AI 合规自查（红线与硬指标）   ← 本文档五段结构
## 第二部分：AI 痕迹深度检测（10 维文风痕迹）   ← report-template.md 五段结构
## 第三部分：统一整改路线图                     ← 按"红线 > 结构 > 规范 > 文风"合并排序
```
> 合并版只在用户明确要求"一份完整报告"时输出；否则两份独立交付，避免报告臃肿。
