# AI 高频词库 与 人味表达库（改写取词用）

> 用法：检测时按 A 部分阈值判命中；改写时从 B 部分取人类替代表达（**每 1000 字 1–2 处，勿过量**）。

## A. AI 高频词库

### A.1 过渡词（超阈值必标）

| AI 高频词 | 人类替代写法 | 阈值 |
|---|---|---|
| 在此基础上 | 进而 / 在此之后 / 直接删除 | >1 次 |
| 进一步分析表明 | 分析表明 / 对比可知 | >1 次 |
| 进一步显示 | 显示 / 反映出 | >2 次 |
| 进一步表明 | 表明 / 说明 | >2 次 |
| 综上所述 | 总的来看 / 综合来看 | >1 次 |
| 由此可见 | 这说明 / 可以看出 | >2 次 |
| 值得注意的是 | 直接删除，或改为具体描述 | >1 次 |
| 需要指出的是 | 直接删除 | >1 次 |
| 不难发现 | 我们发现 / 可以看到 | >1 次 |
| 众所周知 | 直接删除，或改为"在 XX 领域" | >0 次 |
| 显而易见 | 直接删除 | >0 次 |
| 毋庸置疑 | 直接删除 | >0 次 |

### A.2 空洞形容词（连续 ≥2 个必标）

**处理原则**：能删就删；不能删就换成具体量化——"完整的分析"→"分析"，"显著的效果"→"效果提升了 XX%"。

## B. 人味表达库

### B.1 口语化表达（每 1000 字 1–2 处；用于解释复杂概念）

| 表达 | 场景 | 示例 |
|---|---|---|
| 说白了 | 解释复杂概念 | 说白了，这个模型就是在拟合数据中的规律。 |
| 换句话说 | 换一种解释 | 换句话说，浓度越高，检测结果越可靠。 |
| 简单来说 | 简化描述 | 简单来说，需要在准确性和效率之间找平衡。 |
| 换个角度看 | 换视角 | 换个角度看，这也反映了数据本身的特点。 |
| 一个细节是 | 指出易忽略处 | 一个细节是，高 BMI 组的样本量只有 2 个。 |
| 值得一提的是 | 真诚强调 | 值得一提的是，该结论在小样本下仍成立。 |
| 有意思的是 | 表达兴趣 | 有意思的是，模型A在低样本场景反而更好。 |
| 不难理解 | 解释显然现象 | 不难理解，孕周越大，胎儿 DNA 浓度越高。 |

### B.2 个人化判断（做选择/判断处用）

我们倾向于 / 我们认为 / 在我们看来 / 我们的经验是 / 我们建议 / 我们选择（+ 因为…）。

示例：*我们倾向于选择简约模型，因为它在新数据上更稳定。*

### B.3 不完美表述（描述不确定结果）

大致 / 大概 / 基本上 / 在一定程度上 / 似乎 / 可能 / 也许 / 有待进一步验证。

示例：*固定队列的 300 次测量误差区间大致为 [12.0, 12.3] 周。*

### B.4 设问句（AI 几乎不用）

- 引出问题：那么，如何在准确性和效率之间找到平衡？
- 质疑结论：为什么会出现这种反直觉的结果？
- 引导思考：这意味着什么？
- 自我质疑：这个结论真的可靠吗？
- 引出对比：模型A和模型B，哪个更适合？

### B.5 其他人类特征

- **破折号插入解释**（AI 习惯用逗号或括号逗号）；
- **长短句交替**：关键结论处用短句独立成句；
- **段落长短参差**：允许一句话成段，也允许 300+ 字长段；
- **具体化**：数字带量纲与场景（"3 次实验中 2 次失败"优于"效果不稳定"）。
